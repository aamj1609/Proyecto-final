CECyTO Vial — Proyecto escolar
Construye aplicaciones web

CONTENIDO
- index.html: estructura y secciones de la aplicación.
- style.css: diseño adaptable para computadora, tableta y celular.
- app.js: navegación, catálogo educativo de faltas, cuestionario interactivo y resultados.
- assets/cecytem-vial.svg: logotipo ilustrativo creado para este prototipo.

CÓMO ABRIR
1. Descomprime CECyTO_Vial.zip.
2. Abre la carpeta en Visual Studio Code.
3. Abre index.html en un navegador, o utiliza Live Server.

FUNCIONES DISPONIBLES
- Navegación por Inicio, Reglamento, Faltas viales, Cuestionario y Resultados.
- Cuestionario de cinco preguntas con selección de respuestas, navegación, retroalimentación y puntuación.
- Guarda el último resultado en localStorage del navegador.
- Ventana de inicio de sesión demostrativa.
- Menú adaptable a pantallas pequeñas.

IMPORTANTE
Este es un prototipo de interfaz de usuario para fines educativos. Los resultados se guardan únicamente en el navegador. El inicio de sesión no autentica usuarios y todavía no existe una base de datos o servidor. El contenido vial es informativo y no sustituye el reglamento oficial vigente. El logotipo incluido es una propuesta gráfica para el proyecto, no un logotipo oficial de CECyTEM.
